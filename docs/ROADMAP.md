## Next candidates

### 1. お気に入り

選手・チームをお気に入り登録し、あとから見返せるようにする。

- 保存先はブラウザのlocalStorage（サーバー保存なし）
- チーム詳細、選手一覧、検索結果などから登録できる導線を用意する
- お気に入りだけを表示する導線を用意する
- 日本語 / English 両対応
- 390pxモバイルで操作しやすいこと

### 2. トレードマシン Lite

2チーム間で選手を選び、サラリーが大まかにマッチするかを確認できる簡易版。

- 放出選手と獲得選手を選べる
- 両チームの送出・受入サラリー合計を表示する
- 差額と簡易マッチ判定を表示する
- 第1エプロン / 第2エプロン超過チームには警告を出す
- 正確なCBA判定ではなく「Lite」であることをUIで明示する
- 390pxモバイルでも選手選択が破綻しないこと

### 3. 共有カード / PWA

- チームや選手の要点をSNS共有しやすいカード画像にする
- PWA対応でホーム画面に追加できるようにする
- 既存のデザイン言語を崩さない
